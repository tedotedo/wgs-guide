# 🧬 WGS Guide

A static companion website for the **NHS Record of Discussion Regarding Genomic Testing** (v4.03).

## Features
- Educational content on WGS, trio testing, results, family impact
- Non-paternity disclosure, unexpected findings, insurance (ABI Code)
- Interactive 3-step form wizard with consent basis (self/child/best interests)
- PDF generation with acknowledgment recording — email to your consultant
- Curated FAQ with 37 Q&A pairs from NHS.uk, Genomics England, Genetic Alliance UK
- Dark mode, fully responsive, accessible
- **No data collection** — all data stays in your browser

## Privacy
This website does not collect, store, or transmit any personal data.

## Local Development
```bash
python3 -m http.server 8080
```

## Deployment
Fully static — no build step. Deploy to Netlify, GitHub Pages, or any static host.
